# SoftVance Task Manager

A full-stack task management system that enables users to create, manage, and track tasks with ease. It includes user authentication, task CRUD operations, and category-based organization to streamline productivity.

---

## 🌐 Live Demo
## 👉 Frontend: https://github.com/SadiaAfrinMim/_Tasko_project_
## 👉 Backend (API base URL): https://backend-lime-three-30.vercel.app/
## 👉 Live Link: https://simple-project-c9ba2.web.app/login

💡 Make sure CORS is configured correctly on your backend to allow requests from your frontend domain.



## 🚀 Features

- **🔐 User Authentication**: Secure login and session management using JWT.
- **📝 Task Management**: Create, update, delete, and categorize tasks.
- **🌐 CORS Support**: Backend configured to handle cross-origin requests.
- **📊 Dashboard Ready**: Intuitive interface built with Ant Design components.
